# GastroIA Logo Usage

## Dark Background Assets

- `apps/desktop/src/renderer/src/assets/gastroia-logo-dark.svg`: horizontal lockup for carbon, black, sidebar, headers, splash screens, and dark modal surfaces.
- `apps/desktop/src/renderer/src/assets/gastroia-logo-dark-mark.svg`: icon-only mark for dark toolbars, app icons inside dark UI, and compact navigation.
- `apps/desktop/src/renderer/src/assets/gastroia-logo-orange-reverse.svg`: reverse lockup for orange brand blocks.
- `docs/brand/gastroia-dark-logo-system.svg`: reference board with main logo, dark applications, orange reverse usage, and palette.

## Palette

| Name | Hex | Usage |
| --- | --- | --- |
| Carbon | `#1F2328` | Main dark backgrounds |
| Vivid Orange | `#FF6A00` | Accent, AI wordmark, nodes, action highlights |
| White | `#FFFFFF` | Main logo strokes/text over dark backgrounds |
| Soft Gray | `#A6ADB6` | Tagline and secondary text |

## Rules

- Use the dark lockup directly on dark UI surfaces; do not place it inside a white square.
- Keep the original dark mark for light backgrounds.
- Use the orange reverse asset only when the container is orange or very warm.
- Do not recolor the neural/plate mark outside the approved white/orange variants.
